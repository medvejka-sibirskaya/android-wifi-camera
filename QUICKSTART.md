# Wi-Fi Camera: обычная камера для видеосвязи

На текущем компьютере компонент уже установлен и проверен.

1. На рабочем столе открой **Wi-Fi Camera**.
2. На телефоне открой наше приложение, нажми «Подключиться», введи адрес и
   четыре цифры из окна компьютера. Адрес запоминается, код меняется при запуске.
3. В Zoom или настройках камеры сайта выбери **Wi-Fi Camera**.

OBS не нужен. Оставь наш приёмник и приложение на телефоне работающими.
В Zoom оставь свои наушники/обычный микрофон. После первой установки камеры перезапусти
Zoom/браузер, если её пока нет в списке.

Телефон подключается к Wi-Fi того же роутера, к которому подключён компьютер.
Компьютер может быть на проводе. USB нужен только для зарядки/установки APK.

Касание видео — полный экран и обратно, вертикально и горизонтально.
Удержание — фокус, два пальца — масштаб. Значки: две стрелки сверху — смена камеры,
шестерёнка — качество/разрешение/тема, внизу фонарь и зеркало.

В окне компьютера «Веб-камера» показывает состояние и порядок выбора камеры.
«Снимок» сохраняет фото, «Настройки → Завершить приёмник» полностью останавливает
передачу. Простое закрытие окна не завершает приёмник.

Для другого ПК: распакуй WifiCamera-Windows.zip в постоянную папку D:/F:,
установи Python 3.11+ x64, один раз запусти setup.cmd и разреши регистрацию камеры.
Затем запускай start.cmd. Android APK устанавливается отдельно.
Не перемещай зарегистрированные DLL: сначала install-camera.ps1 -Uninstall
от администратора, затем установка из нового места.

До 10 кадров/с. Используй только доверенную домашнюю
сеть: HTTP не шифруется. После пяти неверных кодов блокировка на минуту.
Брандмауэр не отключай и порты роутера не открывай наружу.

## Микрофон и запись — Android 0.3.0 / Windows 0.4.0

Подключи телефон и нажми «Микр.» внизу. Разреши микрофон Android.
На ПК дождись «звук поступает». «Слушать» включает/выключает прослушивание
в окне приёмника. Используй наушники, чтобы не было обратной связи.
«Записать видео со звуком» и «Остановить запись» управляют сохранением AVI
в user-data/recordings. Путь есть в настройках. Формат: MJPEG 1280×720,
10 кадров/с + PCM16 mono 16 кГц. Лимит файла — 1 ГиБ, затем начни новый.
При потере видео запись завершается. Микрофон по умолчанию выключен;
уход Android в фон останавливает и видео, и звук. Отдельный микрофон Windows
не создаётся: это прослушивание и запись в нашем приложении.
